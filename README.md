# CosaQui

CosaQui is an open-source geometric display typeface inspired by the metaphysical architecture of Aldo Rossi and his recurring use of primary forms as a distinctive compositional language.

## About

CosaQui is a geometric display typeface inspired by the metaphysical architecture of Aldo Rossi and his recurring use of primary forms as a distinctive compositional language.

Its letterforms are built from an essential vocabulary of geometric primitives, softened by humanist touches that make the design less rigid and more expressive. Its stencil construction recalls Constructivist and Neoplasticist aesthetics.

The result is a playful and modular geometric display sans.

## Status

CosaQui is currently under development.

The character set and technical features are still being refined, and the repository may change as the project evolves.

## Features

- Uppercase and lowercase Latin letters
- Combining diacritics
- Numerals and punctuation
- Arrows
- Esperanto language support
- Stencil construction

The character set is still being expanded.
