# Contributing to CosaQui

Thank you for your interest in contributing to CosaQui.

CosaQui is an open-source geometric display typeface. Contributions, feedback, bug reports, and suggestions that can help improve the project are welcome.

## How you can contribute

You can contribute to CosaQui in different ways, including:

- reporting problems with glyphs, spacing, kerning, or OpenType behavior;
- reporting technical issues with the font source or exported files;
- suggesting improvements or additions to the character set;
- helping test language support;
- improving documentation;
- testing the typeface and sharing useful feedback.

If you are unsure whether your idea fits the project, feel free to open an issue first.

## Reporting an issue

Before opening a new issue, please check whether a similar issue has already been reported.

When reporting a problem with the typeface, please include as much useful information as possible, such as:

- the glyphs or character combinations involved;
- the application and operating system you are using;
- screenshots or examples, when useful;
- a short description of the expected and actual result.

For issues related to language support, please specify the language and the characters or combinations involved.

Clear examples make issues much easier to understand and address.

## Pull requests

Pull requests are welcome.

For substantial changes, especially those affecting the design of the typeface, its character set, or language support, opening an issue first is recommended so the proposal can be discussed before significant work is undertaken.

When submitting a pull request:

1. Fork the repository and create a dedicated branch for your changes.
2. Keep each pull request focused on a specific issue or improvement.
3. Clearly describe what you changed and why.
4. When relevant, include visual examples or screenshots.
5. Make sure your changes do not unintentionally affect other parts of the typeface.

Please note that not every proposed change will necessarily be incorporated. CosaQui has a specific visual identity and design logic, and contributions will be evaluated for their consistency with the project.

## Licensing

Before contributing, please review the license included in this repository.

Any contribution should be compatible with the licensing terms that apply to the files being modified.

## Thank you

CosaQui is shared as an open-source project so that it can be used, tested, discussed, and improved collectively.

Every thoughtful contribution helps make the project better.
